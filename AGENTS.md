# clone-tabnews-ia

Clone do [TabNews](https://tabnews.com.br), feito para o curso [curso.dev](https://curso.dev), com agentes de IA escrevendo o código.

## Stack

- Next.js (App Router)
- React

## Comandos

- `npm run dev`: servidor de desenvolvimento na porta 8000
- `npm run build`: build de produção
- `npm run start`: servidor de produção na porta 8000
